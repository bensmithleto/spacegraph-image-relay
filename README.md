# spacegraph-image-relay

Temporary copies of company images (product images and logos) for import into the Spacegraph marketplace.
The companies' own websites refuse automated downloads, so the import cannot fetch these files from the original pages.
On import, Spacegraph stores its own copy, and this repository will then be removed.

Every image belongs to the company shown in it. The `logos/*-dark-tile.png` files are each company's own white logo
placed on a plain dark background so that it stays visible on a light page; the logo itself is unchanged.
